# APEX — Sports & Fitness E-Commerce UI

A premium dark-themed sports e-commerce frontend inspired by Gymshark and Nike. Built with vanilla HTML, CSS, and JavaScript.

🌐 **Live Demo:** [apex-e.netlify.app](https://apex-e.netlify.app)

---

## Features

- Sticky navigation with cart counter
- Animated announcement bar ticker
- Full-screen hero with scroll indicator
- Infinite marquee strip
- Category grid with hover effects and image backgrounds
- Product cards with Quick Add, wishlist toggle, and color switcher
- Promo banners section
- Customer reviews grid
- Newsletter signup form
- Mobile responsive with hamburger menu
- Scroll reveal animations

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (DOM manipulation, IntersectionObserver)
- Google Fonts — Bebas Neue, DM Sans
- Deployed on Netlify

## Getting Started

```bash
git clone https://github.com/aslam70/apex-ecommerce.git
cd apex-ecommerce
```

Open `index.html` in your browser — no build step needed.
